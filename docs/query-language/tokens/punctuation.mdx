---
title: "Punctuation"
description: "The four characters that carry meaning in FQL, and the ones that are lexed but never accepted"
---

Four characters carry meaning. Each one is a single token, and each one also ends the word before it — which is why they never need whitespace around them, and why a term cannot contain one.

| Character | Meaning |
|-----------|-------------------------------------------------------------|
| `:` | separates a field from its value (`topic:billing`) |
| `'` | delimits a phrase; `''` inside one is an escaped apostrophe |
| `$` | introduces a parameter reference (`vec:$v`) |
| `@` | selects the graph, glued to the command (`recall@3`) |

## Lexed but never accepted

`(`, `)`, `+`, `-` and `~` are also lexed as tokens, but no production accepts them: a query containing one is rejected wherever it appears. So is every other character that is not a letter or a digit — `;`, `,`, `.`, `_`, `!`, an emoji, a NUL — outside a phrase: each is a token of its own, rejected by name (`";" is only allowed inside a quoted phrase`), and each is data inside quotes. Space, tab, carriage return and newline are the only exceptions: they separate words and instructions.

<Note title="Punctuation inside a word" type="warning">

  A word is letters and digits only, so punctuation never joins one. `foo-bar`, `v1.2` and `2026-01-15` are each rejected at their first special character rather than read as one word — quote the value instead: `'foo-bar'`, `since:'2026-01-15'`. See [Identifiers](/docs/query-language/tokens/identifiers).

</Note>

## Consequences worth remembering

- A date or a time is quoted. `since:'2026-01-15'` and `since:'2026-01-15T10:00:00Z'` parse; bare, the value ends at the first `-` and is rejected. See [Literals](/docs/query-language/tokens/literals).
- A phrase is opaque. Inside quotes nothing is reserved, so `remember 'meeting at 3:30pm about the topic' topic:meetings` stores the colon and the word "topic" literally.
- `''` inside a phrase is one apostrophe: `remember 'alice''s laptop' topic:devices` stores *alice's laptop*.
- The graph selector is glued to the verb. `recall @3` is not a selector — the `@` must follow the command with no whitespace.
