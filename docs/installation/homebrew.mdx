## What the service does

`brew services start fraise` runs the daemon under launchd with `keep_alive`: it restarts on crashes and comes back at login.

| Path | Contents |
|---|---|
| `$(brew --prefix)/var/log/fraise.log` | daemon logs |
| `$(brew --prefix)/etc/fraise/fraise.config.toml` | configuration |

The config file is installed on first install with every setting commented at its default — the file documents itself, and uncommenting a line is the whole act of configuring. It is left alone on upgrades; when a default changes, the new file arrives beside it as `.default`.

This is the Postgres/redis mental model: install once, and let the platform's supervisor own the process.

## Configuring it

Edit the config file, then restart the service:

```sh
brew services restart fraise
```

<Note title="A restart empties the store" type="warning">

  Remember what a restart means before reaching for it: **the store is memory, and bouncing the service is an empty database.** See [Durability](/docs/operations/durability).

</Note>

Every setting, its accepted values and its default are listed in [Configuration](/docs/configuration/overview).
