`memory_tools(client)` returns two tools bound to that client, `recall_memory` and `remember_fact`:

```python
from agents import Agent, Runner
from fraise_sdk import FraiseClient
from fraise_sdk.integrations.openai_agents import memory_tools

fraise = FraiseClient("http://localhost:9876")
agent = Agent(
    name="Assistant",
    instructions="Remember durable facts the user shares, and recall them when relevant.",
    tools=memory_tools(fraise),
)

result = Runner.run_sync(agent, "My favourite colour is orange.")
print(result.final_output)
```

Complete, Docker-runnable agents live in `examples/openai-agents` in the Fraise repository.

## What the tools do

Both are thin wrappers over the [query endpoint](/docs/http-api/endpoints/query): `remember_fact` asserts one self-contained fact with its topics and entities, `recall_memory` seeds a search and returns ranked hits. The client is the same [Python SDK](/docs/integrations/python-sdk) client, and `graph=` binds both tools to one memory graph.

The tools send no vector unless you give them an embedder of their own — `memory_tools(fraise, embedder=OpenAIEmbedder())` — which then encodes the text of every recall and remember they make.

## Instructions matter more than schemas

The tool schemas tell the model *how* to call; the instructions tell it *when*. Recall before answering anything that leans on earlier decisions, and remember only what will still matter in a later session.
