| Setting | Flag | Default | Meaning |
|---------------------------|----------------------------|---------|---------------------------------------------|
| `half-life` | `-half-life` | `168h` | time-decay half-life applied to fact scores |
| `cache-capacity` | `-cache-capacity` | `1000` | size of the LRU of optimised query plans |

```toml
[engine]
half-life = "168h"
cache-capacity = 1024
```

## `half-life`

A recall's score decays with a fact's age on an exponential half-life: the score is multiplied by

$$
0.5^{\, \text{age} / \text{half-life}}
$$

<Note title="Disabling decay" type="note">

  **A negative `half-life` disables decay**; zero, like any unset value, falls back to the default. Decay is ranking, not filtering — see [Temporality](/docs/retrieval/memory-model/temporality).

</Note>

## `cache-capacity`

A count of query **plans**, not bytes. The default 1000 is generous for agents that repeat a handful of query shapes; a repeated query skips optimisation entirely. See [Engine](/docs/architecture/components/engine).
