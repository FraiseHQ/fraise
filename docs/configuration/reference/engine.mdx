| Setting | Flag | Default | Meaning |
|---------------------------|----------------------------|---------|---------------------------------------------|
| `allow-unanchored-recall` | `-allow-unanchored-recall` | `false` | permit a recall with no entity/topic anchor |
| `half-life` | `-half-life` | `168h` | time-decay half-life applied to fact scores |
| `cache-capacity` | `-cache-capacity` | `1000` | size of the LRU of optimised query plans |

```toml
[engine]
allow-unanchored-recall = true
half-life = "168h"
cache-capacity = 1024
```

## `half-life`

A recall's score decays with a fact's age on an exponential half-life:

```text
score *= 0.5 ^ (age / half-life)
```

<Note title="Disabling decay" type="note">

  **A non-positive `half-life` disables decay.** Decay is ranking, not filtering — see [Temporality](/docs/retrieval/memory-model/temporality).

</Note>

## `cache-capacity`

A count of query **plans**, not bytes. The default 1000 is generous for agents that repeat a handful of query shapes; a repeated query skips optimisation entirely. See [Engine](/docs/architecture/components/engine).

## `allow-unanchored-recall`

Off by default: a recall must name at least one `topic:` or `entity:` anchor. Turning it on permits recalls seeded by terms or vectors alone.
