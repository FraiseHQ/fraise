Each algorithm is its own table under `[db]`:

| Setting | Flag | Default | Accepts |
|------------------------------------------|----------------------|----------|----------------------------------|
| `db.search-algorithm.name` | `-search-algorithm` | `excess` | `none` `bfs` `excess` |
| `db.scoring-algorithm.name` | `-scoring-algorithm` | `information` | `information` `excess` `rrf` |
| `db.relevance-model.name` | `-relevance-model` | `bm25` | `bm25` `matchcount` |

```toml
[db.search-algorithm]
name = "excess"

[db.scoring-algorithm]
name = "information"
```

## `search-algorithm`

Selects the traversal moving seed evidence through the graph:

- `excess` — the shipped excess-transmission strategy;
- `bfs` — tree-shaped incidence, available for comparison runs;
- `none` — turns the graph channel off: text/vector search only.

## `scoring-algorithm`

Selects the fold deriving relevance from the pooled evidence:

- `information` — the default: each channel (text, vector, graph) is measured against its total over the recall's pool, and weighted by how sharply it tells the pool's facts apart;
- `excess` — the seed mass plus the attenuated surplus, the fold the excess methodology was first specified with, and the only one keeping the [BM25 floor](/docs/retrieval/ranking/guarantees#bm25-floor);
- `rrf` — available for comparison runs, with its dampening constant fixed at 60, the literature standard, because a comparison baseline is not tunable. It carries **no null model**.

See [The fold](/docs/retrieval/ranking/hybrid-retrieval#the-fold).

## `relevance-model`

Selects how the text index turns a match into a number:

- `bm25` — raw idf-weighted mass $\times$ match breadth against the query's idf mass, what the excess methodology consumes;
- `matchcount` — one point per query-term occurrence, the pre-BM25 ranking, for comparison runs.

## In short

The defaults — `excess` / `information` / `bm25` — are the shipped methodology. The other values exist so a comparison run can isolate one channel at a time, not as tuning surface for production.
